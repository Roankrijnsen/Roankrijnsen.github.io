Mijn ervaring met programmeren

Tijdens mijn opleiding HBO-ICT ben ik begonnen met het leren programmeren. Ik vind het interessant om te ontdekken hoe code werkt en hoe je daarmee zelf iets kunt bouwen. Ik heb gemerkt dat programmeren niet alleen gaat om code typen, maar ook om logisch nadenken en problemen oplossen.

Wat heb ik tot nu toe geleerd?

Ik ben bezig geweest met de basis van JavaScript. Hierbij heb ik onder andere geleerd hoe functies werken, hoe je voorwaarden gebruikt en hoe je tekst kunt controleren. Ook oefen ik met opdrachten waarbij ik zelf moet bedenken hoe ik tot een oplossing kom.

Daarnaast heb ik gewerkt aan mijn eigen portfolio-website met HTML en CSS. Hiermee leer ik hoe je een website opbouwt en hoe je het uiterlijk ervan aanpast. Ik vind het leuk om te zien dat de code die ik schrijf uiteindelijk zichtbaar wordt op mijn website.

Wat vind ik moeilijk?

Soms is het lastig om meteen te begrijpen waarom code niet werkt. Een kleine fout kan ervoor zorgen dat een programma niet doet wat ik verwacht. Daarom moet ik goed naar mijn code kijken, fouten zoeken en verschillende oplossingen proberen.

Ik wil leren om problemen steeds zelfstandiger op te lossen en beter te begrijpen waarom een bepaalde oplossing werkt.

Wat wil ik nog leren?

  • Meer ervaring opdoen met JavaScript.
  • Mijn HTML- en CSS-vaardigheden verbeteren.
  • Zelfstandig grotere programmeeropdrachten maken.
  • Uiteindelijk een eigen applicatie bouwen.

Conclusie

Ik sta nog aan het begin van mijn ontwikkeling als programmeur, maar ik wil mezelf hierin blijven verbeteren. Ik vind het interessant om te ontdekken wat er allemaal mogelijk is met code. Mijn doel is om steeds meer zelf te kunnen maken en uiteindelijk programma's of applicaties te ontwikkelen die echt bruikbaar zijn.
